<Blockquote author="Jay Rungta" source="web.dev" sourceUrl="https://web.dev/blog/baseline-navigation-api">As seen with the preceding examples, the Navigation API fixes deep architectural issues with navigating SPAs, a long-standing pain point among many web developers. ## URLPattern is now Baseline Newly available

<Blockquote author="Jay Rungta" source="web.dev" sourceUrl="https://web.dev/blog/baseline-urlpattern">If you've ever built a feature that needs to react to URL changes, you've likely found yourself writing complex regular expressions or pulling in a third-party library for routing. The URL Pattern API, now Baseline Newly available, provides a standardized, powerful, and interoperable solution for this common challenge.</Blockquote>

## LCP and INP are now Baseline Newly available

<Blockquote author="Barry Pollard, Michal Mocny" source="web.dev" sourceUrl="https://web.dev/blog/lcp-and-inp-are-now-baseline-newly-available">With the release of Safari 26.2 on December 12th, web performance got a fantastic end of year gift with Largest Contentful Paint \(LCP\) and Interaction to Next Paint \(INP\) becoming Baseline Newly available as the latest version of all major browsers now include the Largest Contentful Paint API and Event Timing API needed to measure these metrics. This was part of the Interop 2025 project, and it's great to see these delivered this year!</Blockquote>

## WebGPU is now supported in major browsers

<Blockquote author="François Beaufort" source="web.dev" sourceUrl="https://web.dev/blog/webgpu-supported-major-browsers">Big news for web developers and users. WebGPU—the powerful API for running high-performance 3D graphics and general-purpose GPU computations—is officially supported across Chrome, Edge, Firefox, and Safari. This means the future of high-end, in-browser experiences like AAA gaming, complex 3D modeling, and advanced AI applications is now!</Blockquote>
